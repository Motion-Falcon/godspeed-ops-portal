NOTES
------
- #4 sends TWO emails when the recruiter-created profile also creates a new auth account:
    (a) Supabase verification email  — sent automatically by Supabase on signUp()
    (b) Welcome email                — sent by SendGrid via emailNotifier middleware
  The jobseeker's password is system-generated and only returned in the API response
  to the recruiter; the jobseeker must use "Forgot Password" to set their own password.

- #1 and the unverified path of #2a use Supabase's inviteUserByEmail, which sends
  Supabase's built-in invitation email (template customisable in Supabase dashboard).

- For #7, #8, #9: billing email is preferred over primary email when both are set.

- For #10: CC list is built dynamically from client record flags (invoice_cc2,
  invoice_cc_dispatch, invoice_cc_accounts, etc.) plus the INVOICE_CC_EMAILS env var.

- For #11 and #12: each recipient receives a unique consent link with their own token.
